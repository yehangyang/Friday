# 知识库

按照知识的适用范围来划分，主要是根据知识在多大程度上具有普适性、通用性或特定性。这种分类有助于理解知识在不同场景、领域或人群中的可迁移性和应用边界。
一下按适用范围广度划分（从普遍到特殊）

1. 普适性知识（Universal Knowledge）
定义：适用于全人类、自然界或逻辑系统，在任何时间、地点、文化中都成立。
特点：具有高度客观性、可验证性和跨文化一致性。
例子：
数学定理：如勾股定理（a² + b² = c²，在欧氏几何中恒成立）。
自然规律：如万有引力定律、能量守恒定律。
逻辑规则：如“非A即非A”（排中律）。
✅ 适用范围：全宇宙（理论上）、所有理性认知主体。

2. 通用性知识（Domain-General Knowledge）
定义：适用于多个领域或广泛社会情境，但不一定具有绝对普适性。
特点：可迁移性强，常用于问题解决、沟通、批判性思维等。
例子：
阅读理解能力、基本统计常识（如平均数、概率）。
科学方法（观察→假设→实验→结论）。
基础编程逻辑（如循环、条件判断）可用于多种语言和场景。
✅ 适用范围：跨学科、跨行业、多数现代社会场景。

3. 领域特定知识（Domain-Specific Knowledge）
定义：仅在某一专业领域、行业或任务中有效或有意义。
特点：深度高、术语密集、对外行难以理解。
例子：
航空工程中的翼型气动设计原理。
临床医学中的ICU患者液体管理方案。
金融衍生品定价中的Black-Scholes模型。
✅ 适用范围：限定于特定专业社群或实践场景。

4. 情境性知识（Contextual Knowledge）
定义：只在特定时间、地点、组织或人际关系中有效。
特点：高度依赖具体环境，难以迁移。
例子：
某公司内部报销流程的具体操作步骤。
某村庄的传统节庆仪式安排。
一个项目团队约定的沟通暗号或工作习惯。
✅ 适用范围：极小范围，如某个组织、社区、临时团队。
